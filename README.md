# 🌊 Seaquake Alarm System 🚨

## 📌 Project Overview
The Seaquake Alarm System is an early warning system designed to detect underwater vibrations and alert people in coastal areas. It helps improve safety by giving quick warnings during natural disturbances.

---

## 🎯 Objective
To build a simple and effective system that can detect sea vibrations and trigger an alarm for safety purposes.

---

## ⚙️ Features
- Detects vibration in water/sea
- Triggers buzzer alarm 🚨
- Simple real-time alert system
- Helps in coastal disaster warning

---

## 🔧 Components Used
1.Arduino Uno
2.potentiometer
3.LED
4.piezo Buzzer
5.Resistor-220ohm
6.Bread Board

## 🧠 Working Principle
When the sensor detects unusual vibration, the system activates a buzzer to alert nearby people.
